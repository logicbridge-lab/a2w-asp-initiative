# A2W/ASP Initiative — LogicBridge

Agent-to-Web (A2W) and Agentic Site Profile (ASP) are an open-standard and open-corpus initiative by LogicBridge to make the web more legible, safe, and efficient for autonomous agents.

## Vision

A2W is an open standard for structured interaction between autonomous agents and websites. ASP is a site-level profile that declares identity, resources, actions, policies, and evidence. Long term, domains publish an ASP alongside their human site, ideally under /.well-known/, so agents can use a domain-controlled, machine-readable interface instead of scraping human pages.

## What This Repo Will Contain

Schema and spec for ASP, crawler and extraction tooling, benchmark harness and task definitions, monthly open releases covering crawl artifacts, ASP Drafts, and benchmarks, and documentation and community guidelines.

## Status

This is an early-stage initiative. The first public artifacts are a2w-asp-research-report.md as a research-style report, a2w_asp_scientific_paper_of_intent.md as a scientific paper of intent, a2w_asp_initiative_corpus.md as the internal corpus for LogicBridge and Hermes agents, hermes_org_a2w_brief.md as the brief for Hermes (org), and hermes_pmdev_a2w_brief.md as the brief for Hermes (pmdev).

## How to Follow or Contribute

If you are interested in agent systems, web infrastructure, open data and standards, or digital governance, watch this space. Future work includes public schema discussions, open-source crawler and benchmark code, monthly corpus releases, and opportunities for academic and community collaboration.
